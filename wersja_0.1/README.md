# Planer Studenta - wersja robocza 1/3

To jest wczesna wersja projektu przygotowana na poczatkowy etap prac.
Aplikacja zawiera podstawowe logowanie, rejestracje oraz prosty kalendarz
wydarzen studenckich.

## Zaimplementowane

- rejestracja i logowanie uzytkownika,
- dodawanie wydarzen do kalendarza,
- wyswietlanie wydarzen w widoku miesiaca,
- edycja i usuwanie wlasnych wydarzen,
- podstawowe typy wydarzen: egzamin, projekt, zajecia, inne,
- prosty schemat bazy MySQL.

## Jeszcze do zrobienia

- raporty miesieczne,
- znajomi i udostepnianie wydarzen,
- przypomnienia przegladarkowe,
- wydarzenia cykliczne,
- rozbudowane filtry,
- lepsza walidacja i obsluga bledow,
- finalne dopracowanie wygladu.

## Uruchomienie

1. Utworz baze MySQL.
2. Wgraj plik `database.sql`.
3. Uzupelnij dane polaczenia w `config.php`.
4. Otworz `register.php` i zaloz pierwsze konto.
