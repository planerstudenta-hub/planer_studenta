Planer Studenta - wersja 0.1

To jest wczesna wersja projektu przygotowana na poczatkowy etap prac.
Aplikacja zawiera podstawowe logowanie, rejestracje oraz prosty kalendarz
wydarzen studenckich.

Zaimplementowane

- rejestracja i logowanie uzytkownika,
- dodawanie wydarzen do kalendarza,
- wyswietlanie wydarzen w widoku miesiaca,
- edycja i usuwanie wlasnych wydarzen,
- podstawowe typy wydarzen: egzamin, projekt, zajecia, inne,
- prosty schemat bazy MySQL.
